Plug & Play

Or use the SDK in your app

Works with any LLM. Memories live in a local SQLite file by default; pass supabase_url and supabase_key for a server-side app.

Python — OpenAI
from openai import OpenAI
from dolphin_memory import DolphinMemory

client = OpenAI()
memory = DolphinMemory()  # local SQLite, no setup

def chat(message, user_id):
    memory.add(message, user_id=user_id)
    context = memory.get_context(message, user_id=user_id)

    return client.chat.completions.create(
        model="gpt-4o",
        messages=[
            {"role": "system", "content": f"User context:\n{context}"},
            {"role": "user", "content": message},
        ]
    ).choices[0].message.content
Python — Google Gemini
import google.generativeai as genai
from dolphin_memory import DolphinMemory

genai.configure(api_key="...")
model = genai.GenerativeModel("gemini-2.5-flash")
memory = DolphinMemory()  # local SQLite, no setup

def chat(message, user_id):
    memory.add(message, user_id=user_id)
    context = memory.get_context(message, user_id=user_id)
    return model.generate_content(
        f"User context:\n{context}\n\nUser: {message}"
    )
Python — LangChain
from langchain_openai import ChatOpenAI
from dolphin_memory import DolphinMemory

llm = ChatOpenAI(model="gpt-4o")
memory = DolphinMemory()  # local SQLite, no setup

context = memory.get_context("Tell me about myself", user_id="u1")
response = llm.invoke(f"Context:\n{context}\n\nUser: Tell me about myself")
Python — FastAPI
from fastapi import FastAPI
from dolphin_memory import DolphinMemory

app = FastAPI()
memory = DolphinMemory()  # local SQLite, no setup
memory.prewarm()  # Load models at startup

@app.post("/chat")
async def chat(message: str, user_id: str):
    memory.add(message, user_id=user_id)
    context = memory.get_context(message, user_id=user_id)
    return {"context": context}  # Pass to your LLM of choice
Get Started

SDK in 4 steps

Storing and searching work out of the box. The knowledge graph needs an LLM, by default a local Ollama model.

1

Install the SDK

pip install "git+https://github.com/DewashishCodes/dolphin@main#subdirectory=sdk"

0.2.0 is not on PyPI yet; pip install dolphin-memory currently gives 0.1.0, which needs Supabase.

2

Set up local AI

Run dolphin setup to install Ollama and pull llama3.2.

3

Verify health

Run dolphin doctor to check that everything is healthy.

4

Add your first memory

DolphinMemory().add("I love building AI agents", user_id="me")
